# Introduction

### Purpose

This platform is designed to store data about urban objects such as residential buildins, schools, parks, bridges, towers and so on. Also on this platform it's possible to track changes taking place in the city (Chisinau, in my case).

### Scope

Urban Planning

### Definitions, Acronyms, and Abbreviations

1. **Urban Object (UO)** - is a city object that makes sense to register in the system.
2. **Urban Change (UC)** - is something that results in creation, destruction or significant change of a city.
3. **History of Changes (HoC)** - is a sequence of changes which is associated with an urban object.
4. **Urban Object Version (UOV)** - is an entity that arises as a result of changes which happened to an UC.
